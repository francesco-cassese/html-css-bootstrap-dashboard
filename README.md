# HTML CSS Bootstrap Dashboard

## 📌 Descrizione
Questo progetto consiste nella replica del layout responsive di una **Dashboard** (pannello di controllo) di un'applicazione web. L'obiettivo principale è l'utilizzo di **Bootstrap 5** per gestire la complessità di una interfaccia ricca di dati, tabelle e componenti interattivi, garantendo una perfetta visualizzazione su ogni dispositivo.

## 🛠️ Tecnologie Utilizzate
* **HTML5**: Struttura semantica dei contenuti.
* **CSS3**: Stili custom per sovrascrivere o integrare il framework.
* **Bootstrap 5**: Utilizzo del sistema a griglia, utility classes e componenti.

### 📂 Struttura del Progetto
```text
htmlcss-bootstrap-dashboard/
├── css/
│   └── style.css       # Personalizzazioni e override di Bootstrap
├── img/                # Asset grafici (es. loghi, avatar)
├── index.html          # Dashboard principale (visualizzazione dati)
├── new-book.html       # Pagina form per l'aggiunta di nuovi elementi
└── README.md           # Documentazione
```
